## 概要

Zircon Mining Botは、Discordサーバー向けの採掘ゲームボットです。ユーザーは4つの国（Brave、Freedom、Glory、Peaceful）に所属してジルコン（💎）を採掘し、個人・国別のランキングを競うことができます。

### 主な機能

| 機能 | 説明 |
|------|------|
| 採掘システム | 定時アナウンスで採掘ボタンが表示され、ユーザーが採掘を行う |
| ランキング | 個人・国別の採掘量ランキングを表示 |
| 統計表示 | 個人の採掘履歴や国別統計を確認可能 |
| 確率調整 | ロール別・全体の採掘確率をカスタマイズ可能 |

### 採掘結果の種類

| 結果 | デフォルト確率 | デフォルト獲得量 |
|------|---------------|------------------|
| Excellent | 3% | 10 💎 |
| Great | 22% | 3 💎 |
| Good | 75% | 1 💎 |

## 運営コマンド一覧

> ⚠️ **重要**: すべての運営コマンドは **管理チャンネル** でのみ実行可能です。

### `/zmst` - 鉱山営業状況の管理

鉱山のOPEN/CLOSE状態を表示・変更します。

```
/zmst
```

- **OPEN**: 採掘アナウンスが流れ、ユーザーが採掘可能
- **CLOSE**: アナウンスが停止し、採掘不可

---

### `/zmrank` - ランキング表示

ランキング情報を表示します。

```
/zmrank
```

表示可能なランキング：
- 個人ランキング（今回・累計）
- 国別ランキング（今回・累計）

---

### `/zmadd` - ジルコン付与

指定したユーザーにジルコンを手動で付与します。

```
/zmadd <amount> <user>
```

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| amount | 付与するジルコン数 | 100 |
| user | 対象ユーザー | @username |

**使用例:**
```
/zmadd 50 @username
```
→ @usernameに50ジルコンを付与

---

### `/zmmsg` - メッセージ投稿

採掘チャンネルにメッセージを投稿します。

```
/zmmsg <message>
```

**使用例:**
```
/zmmsg 本日のイベントお知らせ：特別採掘イベント開催中！
```

---

### `/zmannounce` - 手動アナウンス

採掘アナウンスを手動で送信します。同時に全ユーザーの「採掘済み」フラグもリセットされます。

```
/zmannounce
```

**用途:**
- 定時アナウンス以外のタイミングで採掘を開始したい場合
- テスト目的

---

### `/zmtime` - 採掘時間設定

採掘アナウンスの配信時間を設定します。

```
/zmtime [hours] [minutes]
```

| パラメータ | 説明 | 形式 |
|-----------|------|------|
| hours | アナウンス時刻（時） | カンマ区切りで複数指定可 |
| minutes | アナウンス時刻（分） | カンマ区切りで複数指定可 |

**使用例:**

```
/zmtime
```
→ 現在の設定を表示

```
/zmtime 0,12 0
```
→ 0時0分と12時0分にアナウンス

```
/zmtime 9,18,21 0,30
```
→ 9時、18時、21時のそれぞれ0分と30分にアナウンス（計6回/日）

---

### `/zmprob` - 採掘確率設定

採掘確率とジルコン獲得数を表示・変更します。

```
/zmprob [id] [prob] [zirnum]
```

| パラメータ | 説明 |
|-----------|------|
| id | 結果タイプ（0=Excellent, 1=Great, 2=Good） |
| prob | 発生確率（%）|
| zirnum | 獲得ジルコン数 |

**使用例:**

```
/zmprob
```
→ 現在の確率設定を表示

```
/zmprob 0 5 15
```
→ Excellentの確率を5%、獲得量を15に変更

```
/zmprob 1 30 5
```
→ Greatの確率を30%、獲得量を5に変更

> ⚠️ **注意**: Goodの確率は「100% - Excellent確率 - Great確率」で自動計算されます。

---

### `/zmrole` - ロール別確率設定

特定のロールを持つユーザーに対して、採掘確率をカスタマイズします。

```
/zmrole [ロール] [Great確率] [Excellent確率] [優先度]
```

| パラメータ | 説明 |
|-----------|------|
| ロール | 対象のDiscordロール |
| Great確率 | Great発生確率（%） |
| Excellent確率 | Excellent発生確率（%） |
| 優先度 | 複数ロール保持時の適用優先度（小さいほど優先） |

**使用例:**

```
/zmrole
```
→ 現在のロール別確率設定を一覧表示

```
/zmrole @VIPロール 40 15 1
```
→ VIPロールにGreat40%、Excellent15%を設定（優先度1）

```
/zmrole @VIPロール
```
→ VIPロールの設定を削除

**優先度について:**
- ユーザーが複数のロールを持っている場合、優先度が最も小さいロールの確率が適用されます
- 設定がないロールを持つユーザーには、共通確率（`/zmprob`で設定）が適用されます

---

### `/zmreset` - データベースリセット

データベースをリセットします。

```
/zmreset <reset_type>
```

| reset_type | 説明 |
|-----------|------|
| mining | 採掘DB（今回分）のみリセット |
| all | 採掘DBと累計DBの両方をリセット |

> ⚠️ **警告**: この操作は取り消せません。実行前に確認ダイアログが表示されます。

---

### `/zmhelp` - ヘルプ表示

運営コマンドの一覧を表示します。

```
/zmhelp
```

## 日常運用

### 定常運用フロー

```
┌─────────────────────────────────────────────┐
│                  日常運用                     │
├─────────────────────────────────────────────┤
│  1. 鉱山OPEN確認（/zmst）                     │
│           ↓                                 │
│  2. 定時アナウンス自動配信                    │
│           ↓                                 │
│  3. ユーザーが採掘ボタンを押す                │
│           ↓                                 │
│  4. Excellent発生時、国チャンネルに通知       │
│           ↓                                 │
│  5. 24時間ごとに自動バックアップ              │
└─────────────────────────────────────────────┘
```

### シーズン切り替え時の運用

1. **現在のランキングを保存**
   - `/zmrank` でランキングを表示・スクリーンショット保存

2. **鉱山をクローズ**
   - `/zmst` → CLOSEに変更

3. **データリセット**
   - `/zmreset mining` で今回分のデータをリセット
   - または `/zmreset all` で累計含め全リセット

4. **鉱山を再オープン**
   - `/zmst` → OPENに変更

5. **新シーズン開始アナウンス**
   - `/zmmsg 新シーズン開始！今シーズンも採掘頑張りましょう！`

## トラブルシューティング

### Botが応答しない

1. **Botがオンラインか確認**
   - Discordのメンバーリストでオンライン状態を確認
   - オフラインの場合はBot開発者に連絡

2. **管理チャンネルで実行しているか確認**
   - 運営コマンドは管理チャンネルでのみ動作します

### 採掘ができない

| 症状 | 原因 | 対処法 |
|------|------|--------|
| 「鉱山は閉まっています」 | 鉱山がCLOSE状態 | `/zmst` でOPENに変更 |
| 「採掘用のロールを持っていない」 | ユーザーが採掘ロールを持っていない | ユーザーに採掘ロールを付与 |
| 「本日の採掘は完了しています」 | 既に採掘済み | 次回アナウンスを待つ |
| ボタンが表示されない | アナウンスが未送信 | `/zmannounce` で手動送信 |

### コマンドが見つからない

- Bot再起動後、Discordがコマンドを認識するまで数分かかる場合があります
- 解決しない場合はBot開発者に連絡

## FAQ

### Q: 採掘時間を複数設定できますか？

A: はい。`/zmtime` コマンドでカンマ区切りで複数の時刻を指定できます。

```
/zmtime 0,6,12,18 0
```
→ 0時、6時、12時、18時の0分にアナウンス

### Q: 特定ユーザーの採掘確率を上げたい

A: `/zmrole` コマンドで対象ユーザーが持つロールに対して確率を設定してください。

### Q: イベント時だけ確率を上げたい

A: `/zmprob` で一時的に確率を変更し、イベント終了後に元に戻してください。

### Q: 国に所属していないユーザーも採掘できますか？

A: はい。採掘ロールを持っていれば採掘可能です。Excellent時の通知は国未所属用チャンネルに送信されます。

### Q: 累計データを維持したまま今シーズンだけリセットしたい

A: `/zmreset mining` を使用してください。累計データは維持されます。

### Q: データの復旧はできますか？

A: 自動バックアップが24時間ごとに実行されています。復旧が必要な場合はBot開発者に連絡してください。
